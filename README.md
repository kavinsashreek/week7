Each Java file has its own package and a `main()` method demonstrating the expected behavior.

## Run a solution

From the repository root, compile a file to a temporary output directory and run its fully qualified class name. Example:

```bash
javac -d out Assignment/M1/Character.java
java -cp out assignment.m1.Character
```

Replace the file path and class name to run another solution.
